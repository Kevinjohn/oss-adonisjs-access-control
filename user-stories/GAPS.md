## Decision gap

The specification’s [scope deletion contract](../docs/maintainers/design/spec-access-control.md#55-scope-deletion-support) defines membership cleanup before host scope deletion. The service deletes membership rows, while Account Kit retains pending invitations. Access Control’s actor-authorized revocation needs an active membership in the existing scope, so the host must handle invitations while the scope still exists. [US-ACCESS-25](US-ACCESS-25-delete-scope-memberships.md) records this ordering, and [US-ACCESS-10](US-ACCESS-10-accept-invitation.md) records the recovery boundary. Coordination with concurrent invitation sends and recovery for invitations left after deletion remain host decisions.
